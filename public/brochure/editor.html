📖 GUÍA RÁPIDA DE EDICIÓN

Paso 1: Prepara tus imágenes

Reemplaza las imágenes en public/brochure/img/ con tus propias imágenes. Mantén los mismos nombres de archivo.

Recomendaciones de imagen:
• Imágenes de fondo: Alto contraste para legibilidad de texto
• Imágenes de perfil: Aspecto 4:3 o 3:4 según la sección
• Logos: PNG transparente preferiblemente
• Resolución: 72-96 DPI es suficiente para web

Paso 2: Abre el editor de código

Abre el archivo en tu editor favorito:

📁 public/brochure/index.html
Puedes usar: VS Code, Sublime Text, Notepad++, o cualquier editor de texto

Paso 3: Busca y reemplaza

Usa Ctrl+F (Buscar) en tu editor para encontrar los textos que quieres cambiar:

Ejemplo: Busca "CUSCO · PERÚ · DESDE 2011" Reemplaza por: "TU_CIUDAD · TU_PAÍS · DESDE TU_AÑO"

Colores principales (opcional)

Si quieres cambiar los colores, busca estos códigos:

#12100D = Fondo oscuro (negro) #EDE7DB = Texto claro (beige) #7FCF52 = Verde principal (acento) #4FA83A = Verde oscuro

Paso 4: Guarda y visualiza

1. Guarda el archivo (Ctrl+S)
2. Recarga el navegador (F5)
3. ¡Verás tus cambios!

✅ ¡Listo! Tu brochure actualizado y con el diseño intacto.
